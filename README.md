# sgd-epigenetic-landscape-review

Code for the figures of

> A. C. Fassoni. *Stochastic gradient descent on the epigenetic landscape: a unified framework for cellular plasticity, tumor heterogeneity, and the asymptotic irrelevance of fitness.* Preprint, 2026. arXiv.

The proofs of the continuum results are in a separate paper, whose code is in [uniform-competition-continuum](https://github.com/arturfassoni/uniform-competition-continuum).

## Figures

| Script | Output | Figure | What it shows |
|---|---|---|---|
| — | — | 1 | Schematic roadmap of the framework (drawn separately, not generated by code) |
| `fig2_fitness_imprint.py` | `fig2_fitness_imprint.pdf` | 2 | Under uniform competition, the imprint of fitness on the phenotypic composition decays at the spectral gap; memory time in the Kramers regime |
| `fig3_pde.py` | `fig3_pde.pdf` | 3 | The nonlinear PDE on the multi-well landscape converges to the stationary density of the switching dynamics |
| `fig4_examples.py` (uses `sde_core.py`) | `fig4_examples.pdf` | 4 | Single-cell SDE simulations: uniform, exponential, Gaussian, heavy-tailed and multi-well stationary distributions |
| `fig5_limit_cycle.py` | `fig5_limit_cycle.pdf` | 5 | Counterexample of Appendix A: under weighted competition the population oscillates on a limit cycle |

The multi-well landscape of Figures 1(e,f), 3 and 4(e) is a cubic spline through fixed control points, defined in `fig3_pde.py` and `fig4_examples.py`.

## Running

```bash
pip install -r requirements.txt
python3 fig2_fitness_imprint.py
python3 fig3_pde.py
python3 fig4_examples.py
python3 fig5_limit_cycle.py
```

Each script writes its PDF to the current folder and prints the numbers quoted in the text. `fig4_examples.py` takes about a minute; the others take a few seconds. Tested with Python 3.11, NumPy 2.4, SciPy 1.17 and Matplotlib 3.11.
